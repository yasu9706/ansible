# syncかasyncか
## asyncについて
データの変更が生じた際に書き込みを行って同期を待つかどうか。

asyncではパフォーマンスは向上するが信頼性や一貫性はsyncほどには期待できない。

例えばマウントした状態でlsコマンドを実行して何も表示されずプロンプトが
返ってこない場合がある。これはサーバ側のファイルシステムで
メタデータ更新が追いついていない場合にで整合性確認のため無限に待ち状態
(Dステート)に入っている。

大量の書き込み要求がディスク性能を超えて溜まっていくとサーバ側のIOサブシステムが
飽和する。このときにlsコマンドを実行すると管理用の要求が書き込み要求の中に埋もれ、
結果的にプロンプトが返ってこなくなる。

## asyncと一緒に指定すべきオプション
パフォーマンスのためにasyncを設定したい場合には次のオプションも指定する。

- no_subtree_check(サーバ側)
- actimeoで3~10のような小さい値を使用、0は逆効果(クライアント側)
- nfsvers=4.1

### no_subtree_check
subtreeとはいわゆるサブディレクトリのこと。
例えば/a/bという構造で、ディレクトリaからみてbはサブディレクトリ、サブツリーになる。

subtree_check/no_subtree_checkはセキュリティのための機能で、
例えば/exportにパーティション/dev/sdb1をマウントしており、
/export/nfs01のようにパーティションの一部をnfsで公開する場合、
クライアントが何らかの方法で/export/secretのような階層の情報を手に入れても
subtree_checkが有効であればアクセスがブロックされる。

現代ではno_subtree_checkが一般的となったが、subtree_checkには下記のような問題があった
- パフォーマンスに悪影響が出る
- Stale File Handleエラーが頻発する。
  - NFSではクライアントはファイルアクセスに/a/b/cdのようなパス名ではなく  
    ファイルハンドルというIDを使用する。
  - subtree_checkが有効だと、このファイルハンドラが示すファイルは  
    現在も許可されたサブツリー下にあるか、というチェックを行う
  - ファイルが別のディレクトリに移動されるとキャッシュのタイミングや  
    ファイルシステムの構造によって、あるはずの場所にファイルがない、という
    Stale File Handleエラーが返される
- パーティションをマウントしたディレクトリ全体をエクスポートしている場合はそもそも意味がない
  - /exportにパーティションをマウントして/exportをエクスポートしていれば  
    /export/nfs01だろうが/export/secretだろうが関係ない
  - ただし例えば/export/other_fsに別のパーティションをマウントしている場合には
    no_subtree_checkでもcrossmntオプションを指定する必要がある
  - 同様にエクスポートのオプションでfsid=0を指定している場合も、
    クライアントは192.168.0.1:/のようにルートファイルシステムが
    エクスポートされているものとして認識するのでチェックが不要

### actimeo
acとはattributes cacheのことで、ファイルサイズや作成日時などのメタデータのキャッシュ。
つまりlsを叩いて帰ってくる情報。

actimeoではacregmin, acregmax(ファイルのキャッシュ時間の最小値、最大値), 
acdirmin, acdirmax(ディレクトリのキャッシュ時間の最小値、最大値)を一括で
指定秒に設定する。

これに3~10を設定するとメタデータのキャッシュが書き込まれてlsのハングを防ぐことができる。

逆に0を指定するとデータの読み書きのたびにメタデータの書き込みが生じ、
結局asyncの指定が意味のないものになる。

### nfs4を使う
nfs4.1からはセッション管理が強化されasync使用時にネットワークが瞬断しても
リカバリがスムーズになる。


## Dステート
psコマンドでのステータス欄(STAT)でDと表記されるためD-stateなどと呼ばれる。
Linuxにおけるプロセスのステータスは大きく5つに分かれる。

- Running / Runnable (R)
- Uninterruptable Sleep (D)
- Interruptable Sleep (S)
- Stopped (T)
- Zombie (Z)
