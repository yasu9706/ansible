# vimにおけるsourceコマンドとrutimeコマンドの違い

## sourceコマンド
ファイル名を引数にとって、そのファイルをExコマンドが書かれたファイルとして
読み込む。
基本的に指定するファイルは絶対パスになる。
ただvim起動時のカレントディレクトリからの相対パスでも多分動作する。

vimで`:h source`も参照

`*`のようないわゆるglobは使えない？

## runtimeコマンド
sourceコマンドと同様にExコマンドが記載されたファイルを読み込む。
違いとしてはruntimepathという変数に指定された、複数のパスからファイルを検索する。
またglobも動作する。
runtimepathの内容の確認には、vimで`:set runtimepath`を実行する。


## どちらを使うか?

vim起動時に読み込むファイル、いわゆるplugin、を意図して一箇所にまとめて
配置することで管理する、という観点ではこのglobが動作するという特性上、
runtimeを使用する方が適切に思われる。
逆に普段のvim起動時には使わないが、テスト用に書いたvimscriptファイルを
テキトーな場所から場所から今回だけ読み込む、というような意思を明確にしたい場合は、
sourceコマンドを使うのが適切に思われる。

runtimeの欠点はruntimepathのいずれからマッチしたファイルを実行する、という性質上、
実際にはどこにあるファイルが参照されるかを確認しづらい。
